# 九九乘法牌 · 数字小侦探

按课堂描述制作的家庭猜牌游戏。利用乘法口诀、牌的分组和大小顺序，猜出对方桌上的数字；支持与电脑对战、两人共用一台设备轮流玩。

**[打开在线游戏](https://houde0820.github.io/99-card-detective/)** · [主题开发说明](THEMES.md) · [手绘素材说明](ASSETS.md)

## 快速开始

1. 打开在线游戏，进入「设置」。
2. 选择对战方式、牌的范围和每人初始牌数，点击「开始新对局」。
3. 点击对方一张未翻开的牌，直接在牌上输入数字，点 **✓** 确认；点 **×** 取消。
4. 对局结束后，标题栏出现「开始新对局」，点击可沿用本局配置直接重开。需要调整配置时，进入「设置」后再开始。

对局过程中，标题栏的新对局按钮隐藏；仍可通过设置重新开局。胜利弹窗可选择查看牌桌或进入设置再来一局。

## 玩法与推理

- **公共牌堆**：每个数字各一张，两人从同一个牌堆抽牌；初始每人4–6张，默认5张。
- **牌的顺序**：同一数字范围的牌放在一列，每列从下到上递增；各列从右向左由小到大。初级有0–9、10–19、20–29、30–39四个范围，中级增加40–49。
- **隐藏列范围**：牌桌不显示范围标签。默认有牌的列靠右排列，空列不占位置，需要结合分组、顺序和牌面线索推理真实范围。设置中也可选固定位置保留空列。
- **牌背线索**：口诀内数字随机显示一个因数，两个乘数都在1–9内。例如18可以提示2、3、6或9；11、13、17、22、33、39等口诀外数字显示 **X**，0也显示X。因数在开局时分配，对局中保持不变。
- **猜对**：牌翻开并留在桌上。
- **猜错**：对方从公共牌堆抽2张，按大小插入对应位置；不足2张时抽完剩余牌。原牌保留橙色标记和最近一次错误猜测，补牌、排序及刷新后标记仍跟着该牌。
- **轮流行动**：无论猜对或猜错，都换另一人行动。先猜完对方桌上全部牌的人获胜，牌堆里尚未抽出的牌不计入胜负。

例如只有0–9和20–29有牌时，两列相邻靠右；补进10–19的牌后，新增列插入中间，20–29移到右数第三列。翻开的数字可以帮助确定整列的范围。

「看看可能的数字」和电脑都根据可见分组、大小顺序、因数或X提示、自己的数字、已翻开的数字与错误猜测推理，不读取暗牌答案、隐藏的列范围或牌堆内容。

双人模式换手时先遮挡牌面，下一位点击「准备好了，查看我的牌」后继续。

## 设置

除主题皮肤外，下列配置使用横向切换按钮，选中项高亮显示。新对局配置在点击设置内的「开始新对局」后应用；皮肤切换立即生效。

| 配置 | 可选项 | 默认 / 说明 |
| --- | --- | --- |
| 和谁一起玩 | 我和电脑 / 双人轮流 | 默认与电脑对战 |
| 电脑思考方式 | 轻松练习 / 认真挑战 | 默认轻松练习；双人模式禁用此项 |
| 牌的范围 | 初级1–39 / 中级1–49 / 0–39 | 默认1–39，共39张；中级49张；含0版本40张 |
| 每人初始牌数 | 4张 / 5张 / 6张 | 默认5张 |
| 列的摆放 | 右对齐 / 固定位置 | 默认右对齐，隐藏空列和范围位置 |
| 牌背提示怎么分配 | 优先2–9 / 全部1–9 | 默认优先2–9；始终只选择合法因数 |

「轻松练习」随机选择线索，「认真挑战」优先猜候选数字最少的牌。设置内还提供可展开的玩法说明与对局记录。

对局和皮肤选择保存在当前浏览器的本地存储中，刷新可继续。换皮肤不会重新发牌，也不会清除正在输入的数字；清除浏览器站点数据会删除本地进度。

## 主题皮肤

- **晴空积木、薄荷积木、莓果积木**：几何图形、分区配色和带厚度的卡片与按钮。
- **植物大战僵尸风格**：参考经典主菜单，使用手绘蓝天花园、歪斜木牌、灰色石碑、厚描边与刻字字体效果。对方线索是石碑小牌，自己的数字是纸牌。

手绘图片随项目放在 `dist/assets/` 中，字体使用系统字体，无外部图片或字体请求。皮肤样式、页面交互与游戏引擎分别组织，添加皮肤的方法见 [THEMES.md](THEMES.md)，素材生成方式与提示词见 [ASSETS.md](ASSETS.md)。

## 本地运行

项目无需安装第三方依赖，也不需要构建。

```sh
git clone https://github.com/houde0820/99-card-detective.git
cd 99-card-detective
python3 -m http.server 8766 --bind 127.0.0.1 --directory dist
```

打开 [http://127.0.0.1:8766/](http://127.0.0.1:8766/)。也可以直接用浏览器打开 `dist/index.html`，需保留旁边的 `assets/` 文件夹。

## 源码与修改

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` | 主源码，包含主题样式、游戏引擎、设置与页面交互；直接修改此文件 |
| `dist/assets/` | 花园背景与透明石碑素材 |
| `check-game.cjs` | 游戏规则、推理、存档迁移和随机权重测试 |
| `.github/workflows/pages.yml` | 自动测试和GitHub Pages发布 |
| `THEMES.md` | 主题样式和换肤扩展说明 |
| `ASSETS.md` | 手绘素材来源、生成方式和提示词 |

`dist/` 是直接发布的静态源码目录，修改后无需生成另一份构建产物。仓库不包含账户凭证或玩家存档。

### 验证改动

使用Node.js 24，在仓库根目录执行：

```sh
node check-game.cjs
```

当前测试包括：

- 1800局种子模拟，覆盖三种牌范围、4–6张开局，以及公共牌堆守恒、排序插入、牌堆耗尽、胜负判断、旧存档迁移和电脑的暗牌独立性。
- 三组各5000对种子分布对照，检查30–39、因数2、X牌和初始5–9牌的频率微调，同时保留完整牌组与合法因数。
- 60个压缩列小牌桌的穷举对照，检查跨范围推理、翻牌定位、隐藏范围独立性及补牌后猜错标记保留。

页面交互或样式修改还需在浏览器检查：切换配置和主题、开始对局、牌上输入与取消、猜错补牌、结束后重开、刷新恢复，以及手机窄屏布局。上述脚本不代替界面检查。

### 抽牌与因数权重

为让开局更适合练习，游戏做了轻微随机权重调整：

| 对象 | 权重调整 |
| --- | --- |
| 30–39号牌 | 抽取权重乘以0.85 |
| X牌 | 抽取权重乘以0.85，与范围权重叠加 |
| 初始发牌中的5–9号牌 | 额外乘以0.85 |
| 初始发牌中的X牌 | 额外乘以0.85 |
| 可选择多个因数时的提示2 | 相对其他合法因数的权重为0.85 |

初始调整只作用于给两人发的前8–12张牌，即每人所选张数的两倍；后续补牌沿用基础权重。每个数字仍各有一张牌，调整影响抽牌顺序，不删牌。只有因数2可选时仍提示2。已有对局保留原牌堆、提示与配置。

## GitHub Pages自动发布

`main` 是源码与在线预览的同步入口。

1. 修改源码并提交到 `main`，自动触发 **Test and deploy GitHub Pages**。
2. 工作流使用Node.js 24运行 `check-game.cjs`。
3. 测试通过后，将同一提交的整个 `dist/`（含图片素材）发布到GitHub Pages。
4. 在仓库的 [Actions页面](https://github.com/houde0820/99-card-detective/actions) 查看发布结果。

Pull request只运行测试，合并到 `main` 后才发布。也可以在Actions中手动运行工作流。预览地址固定为：

**[https://houde0820.github.io/99-card-detective/](https://houde0820.github.io/99-card-detective/)**

发布产物中的 [version.json](https://houde0820.github.io/99-card-detective/version.json) 记录已发布提交的SHA，可与 `main` 的最新提交核对。若页面仍显示旧界面，先确认工作流发布成功，再刷新页面。

重新部署到其他仓库时，在该仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，再运行发布工作流。
