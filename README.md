# 九九乘法牌 · 数字小侦探

按课堂玩法制作的家庭猜牌游戏，支持与电脑对战，以及两人共用一台设备轮流玩。

[在线游戏](https://jiujiu-card-detective.depeng.chatgpt.site)

## 运行

没有第三方依赖，也不需要构建。直接用浏览器打开 `dist/index.html` 即可玩。

也可以在项目根目录启动本地服务：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory dist
```

然后打开 <http://127.0.0.1:8766/>。

## 当前规则

- 所有牌共用一个牌堆，开局每人抽4张；可选1–39或0–39。
- 四列从右到左依次为0–9、10–19、20–29、30–39；每列从下到上递增。
- 口诀内数字的牌背随机显示一个因数，两个乘数都在1–9内；口诀外数字显示X。
- 点击对方未翻开的牌，在牌上输入数字，点✓确认、点×取消。
- 猜对翻开留桌；猜错，对方从公共牌堆抽两张，按大小插入。不足两张时抽完剩余牌。
- 双方轮流行动，先猜完对方桌上全部牌的一方获胜。
- 猜错的牌保留橙色标记和最近的错误猜测，重新排序和刷新后仍保留。
- 提示与电脑根据牌的位置、牌背提示、已知数字和错误猜测推理，不读取暗牌答案或牌堆内容。

双人模式换人时遮挡牌面。对局保存在当前浏览器的本地存储中，支持继续旧对局。

## 随机权重

新对局中，30–39号牌的抽取权重为其他牌的0.85倍；有其他合法因数可选时，因数2的提示权重为其他因数的0.85倍。

每个数字仍各有一张牌，这个调整影响抽牌顺序，使30–39在前期略少出现。只能提示2的牌仍提示2。已开始的对局继续使用其既有牌堆和提示；刷新网页后新开一局应用新权重。

## 修改与验证

`dist/index.html` 是主源码与交付文件，包含样式、独立游戏引擎和页面交互。保持单文件是为了方便离线使用。

安装Node.js后，在项目根目录运行：

```sh
node check-game.cjs
```

测试覆盖400局确定性对局，以及公共牌堆守恒、排序插入、位置与X推理、牌堆耗尽、旧存档迁移和电脑的暗牌独立性。另有5000组固定种子的均匀与调整权重对照，检查频率只作轻微下降。页面交互改动还需要在浏览器中检查。

## 发布与代码同步

GitHub Pages工作流位于 `.github/workflows/pages.yml`。

- 每次推送到 `main`，自动执行规则测试和随机权重测试，全部通过后直接发布该提交的 `dist/`。
- Pull request只运行测试，合并到 `main` 后自动发布。
- 发布使用同一份 `dist/index.html`，无需复制源码到另一个发布目录。
- 可以在仓库Actions页面手动运行 `Test and deploy GitHub Pages`。
- 发布产物中的 `version.json` 记录本次发布的提交SHA，可用于确认网页与源码是否一致。

### 首次启用

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
3. 在 **Actions → Test and deploy GitHub Pages** 手动运行一次；后续 `main` 更新会自动触发。

Pages启用并发布成功后的默认地址为：

<https://houde0820.github.io/-jiujiu-card-detective/>

GitHub Free支持公开仓库的Pages；私有仓库需要GitHub Pro或其他支持私有Pages的付费方案。保留私有仓库时，先确认账号支持Pages。

原Sites网址仍可使用，Sites需要另行发布。GitHub Pages预览由上述工作流自动跟随GitHub源码更新。

仓库不包含发布压缩包、账户凭证或玩家存档。
